AI Helper

The ``ai_helper`` package provides artificial intelligence-based utilities for assisting users in the development and use of TARgET.

The package includes components that leverage large language models (LLMs) to:

  • Answer questions about the TARgET API and its functionalities.
  • Assist in the construction and manipulation of tree automata and rational tree expressions.
  • Help generate and explain Python code using the TARgET library.
  • Provide guidance on algorithms, transformations, and formal language concepts.
  • Support contributors during the development of the toolkit.

This package is optional and requires additional AI-related dependencies that are not installed as part of the core TARgET package.
