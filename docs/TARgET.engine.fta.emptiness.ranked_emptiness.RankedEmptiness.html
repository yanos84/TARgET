class RankedEmptiness(AbsEmptiness):

View In Hierarchy

Class to check the emptiness of a ranked finite tree automaton (RFTA). The emptiness of an RFTA is determined by checking if there are any states that can be reached from the initial states and lead to a final state through the transitions defined in the automaton. This is done by iteratively marking states as "good" if they can be reached from the initial states and can lead to a final state. If no final state can be marked as "good", then the automaton is considered empty.
