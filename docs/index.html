TARgET (Tree Automata and Rational Expressions Toolkit).

TARgET is a Python library for the manipulation and analysis of finite tree automata, weighted tree automata, rational tree expressions, and their associated algebraic structures.

The toolkit is organized into modular subpackages implementing automata, expressions, semirings, tree data structures, parsing utilities, and transformation algorithms. Together, these components provide a unified framework for research, teaching, and experimentation with tree-language formalisms. The modules include:

  • fta: Finite Tree Automata and Weighted Tree Automata
  • rte: Rational Tree Expressions
  • core: Core data structures and utilities for tree manipulation
  • algebraic: semirings and algebraic structures.
  • engine: internal infrastructure and shared abstractions.
  • transformations: automata and expression transformations.
  • trees: tree data structures and utilities.
  • ai_help: AI-based assistance for user or collaborator contributions.
  • tests : unit tests for the toolkit.
  • gui: graphical user interface for visualizing and interacting with tree automata and expressions.
  • cli: command-line interface for automata and expression operations.
