class UnrankedTree(AbstractTree):

Constructor: UnrankedTree(symbol)

View In Hierarchy

A tree structure where each node can have an arbitrary number of children. This class extends AbstractTree and does not impose any constraints on the number of children a node can have. It provides methods to add children and check if the tree is well-formed, which in this case always returns True since there are no constraints on the number of children.
