Draw a ranked finite tree automaton (RFTA) using Graphviz.

This function generates a visual representation of a ranked finite tree automaton (RFTA) using Graphviz. States are represented as nodes, with final states displayed as double circles. Transition rules are represented as directed edges labeled with the corresponding rule. The resulting graph can be rendered and saved as an image for visualization and analysis purposes. :param fta: The ranked finite tree automaton to draw. :direction: The direction of the graph layout. "TB" for top-to-bottom, "LR" for left-to-right. :returns: A Graphviz ``Digraph`` object representing the visual structure of the automaton. :rtype: graphviz.Digraph
