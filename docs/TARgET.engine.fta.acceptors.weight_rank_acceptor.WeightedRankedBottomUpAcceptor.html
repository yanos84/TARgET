class WeightedRankedBottomUpAcceptor(Acceptor):

View In Hierarchy

Bottom-up acceptor for Weighted Ranked Finite Tree Automata (WRFTA).

Computes, for a given tree, the weight associated with each possible root state using the automaton's semiring.

Method accepts Returns the total acceptance weight of the tree.
Method compute_weights Compute the weights for each possible root state of the given tree. Returns a dictionary mapping each state to its corresponding weight.
